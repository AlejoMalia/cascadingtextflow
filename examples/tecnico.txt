El motor de cache almacena resultados intermedios. Cuando el motor recibe una consulta, el cache responde si la clave existe; si la clave no existe, el motor calcula el resultado y el cache lo guarda. La consulta repetida evita el cálculo. El cache tiene un límite de memoria: al superarlo, el cache elimina las claves más antiguas. Una clave nueva desplaza a la más antigua. El motor mide la tasa de aciertos del cache para ajustar el límite de memoria. Si la tasa baja, el motor amplía el cache; si sube, el motor reduce el límite. Cada consulta deja una huella en el registro, y el registro permite reproducir el cálculo.
