The cache engine stores intermediate results. When the engine receives a query, the cache responds if the key exists; if the key does not exist, the engine computes the result and the cache saves it. A repeated query avoids the computation. The cache has a memory limit: on exceeding it, the cache evicts the oldest keys. A new key displaces the oldest one. The engine measures the hit rate of the cache to adjust the memory limit. If the rate drops, the engine expands the cache; if it rises, the engine reduces the limit. Each query leaves a trace in the log, and the log allows the computation to be replayed.
